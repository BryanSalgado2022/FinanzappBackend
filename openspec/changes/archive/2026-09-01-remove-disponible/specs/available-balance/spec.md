## REMOVED Requirements

### Requirement: Disponible is a running total since the baseline date
**Reason**: Removed after user testing — the "accumulated since a baseline date" model was confusing to understand and explain, and the user decided against keeping it.
**Migration**: None. No successor feature; `ahorros` (a simple manually-set figure, unaffected by this removal) remains available for tracking savings.

### Requirement: Disponible is unavailable until configured
**Reason**: Part of the same removed Disponible feature.
**Migration**: None.

### Requirement: Disponible is scoped to the authenticated user
**Reason**: Part of the same removed Disponible feature.
**Migration**: None.
